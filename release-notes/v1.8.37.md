## 新增与升级

- 桌宠跟随当前使用的项目窗口。呆猫新增中、英、日三种语言的互动台词，气泡字号随角色倍率调整，2 倍时使用 16px。可在设置中试演角色支持的动作，并从文件导入自定义角色。
- 新增 SSH 远程工作区，可在侧栏选择主机、浏览远程目录，启动远程终端和智能体。工作区恢复设置可保存会话、打开的文件、分栏和终端输出快照。
- 文件树支持显示 Git 变更和忽略状态，底部运行面板支持搜索日志并跳转到匹配行。技能市场支持分类浏览、搜索和分页，技能设置支持编辑及切换启用状态。
- 应用从 Termflow 更名为 Krosna。任务监控按项目汇总会话状态，配额面板补充了 Claude、Codex 等智能体的用量信息。

## 问题修复

- 多项目同时打开时，终端输出定向发给所属窗口，后台窗口暂停桌宠重绘和 Git 兜底轮询。减少其他窗口产生输出时对当前窗口打字的干扰。
- 录音电平和实时转写只发给语音浮窗，项目窗口仅接收录音阶段变化。系统输入在投递时确认前台窗口，投递过程中切换窗口会取消发送。终端未确认接收时会提示检查输入框，避免自动重试造成重复输入。
- 修复桌宠气泡字号过小和靠近窗口边缘时文字被截断的问题。设置预览与实际桌宠使用相同的字号，长台词会在窄区域换行。
- 修复终端网格和后台终端尺寸不同步，以及部分 Unicode 字符和组合表情的列宽问题。Codex 会话恢复使用已确认的会话标识，避免重复绑定。
- 改善 Office 文档预览的离线资源加载、编辑器在分屏切换时的状态保留，以及文件搜索和 Git 刷新的重复扫描。

## 升级说明

从 Termflow 升级时请先保存工作并退出旧版，再安装 Krosna。首次启动会迁移兼容的旧配置。手写脚本如使用旧名称，请将新项目配置路径更新为 `.krosna/`，运行时命令更新为 `krosna`。
