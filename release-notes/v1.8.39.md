## 新增与升级

- 标题栏快速搜索使用项目文件索引查找文件名，结果可在侧边栏中定位。后台全文索引仍按项目开启，支持两个汉字的正文查询。索引尚未就绪时，查询可在索引就绪后自动继续。
- 终端中的文件链接可按行打开、在侧边辅助区预览、在资源管理器中定位，或复制路径。操作菜单在链接触发位置附近打开，也支持键盘选择。
- 状态栏新增内存诊断，可记录工作区渲染进程的内存走势，查看终端、回滚缓冲和编辑器数量，并复制诊断摘要。
- 更新窗口展示当前版本、目标版本和下载进度。遇到问题时，可展开并复制技术详情，或打开网络设置和手动下载入口。
- 调整 Git 侧栏的提交区布局，集中显示提交信息、AI 生成入口和提交操作，并提供本地状态刷新按钮。

## 问题修复

- 修复切换项目时，后台文件名搜索和全文搜索可能使用错误项目的问题。
- 修复 Windows 下部分智能体 CLI 的查找问题，并改进 Codex 用量查询的重试。
- 修复像素宠物设置的持久化问题，使切换工作区或重启后能恢复已保存的设置。
- 恢复旧终端画面时显示只读提示，避免把历史输出误认为仍可输入的会话。
- 修复发布期间工作流变更可能阻断 GitHub Release 创建的问题，并保留等待同步国内镜像的发布任务。
