## 新增与升级

- Krosna 现在会同时检查 GitHub 和国内更新服务器。在只能访问其中一个站点的网络上，也能在应用内获取更新。

## 问题修复

- 修复能查到新版本、却因安装包下载地址不可达而卡住的问题。下载失败后会尝试另一个地址，并使用同一份签名校验安装包。
- 更新弹窗现在区分检查失败和下载失败，保留具体错误。已查到版本时，下载失败的弹窗也提供该版本的国内安装包入口。

## 升级说明

- 如果你正在使用 1.8.36 或 1.8.37，且应用内无法连接 GitHub，请保存工作、退出 Krosna，然后手动运行一次 [1.8.38 国内安装包](https://termflow.jianglan.online/releases/Termflow_1.8.38_x64-setup.exe)。安装后，后续版本即可通过双更新源升级。
