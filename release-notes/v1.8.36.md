## 新增与升级

- 应用正式更名为 Krosna，统一桌面应用、项目配置与运行时 CLI 的命名，并保留旧版 Termflow 数据、项目配置和 Hook 的兼容迁移。
- 新增 SSH 远程工作区，支持主机配置、连接认证、远程服务管理，以及远程终端和智能体会话。
- 新增工作区恢复设置，可恢复已打开的会话、文件、分栏布局和编辑位置，并保留终端输出快照供恢复时查看。
- 技能市场支持在工作区标签页中按分类浏览、搜索和分页；技能设置支持内容编辑、启停，以及项目和全局范围安装。Pi 状态扩展纳入 Hook 配置管理。
- 资源管理器增加 Git 状态着色和父目录状态提示，按项目保留目录展开状态，并在外部文件发生变化时增量刷新。
- 底部运行面板增加日志搜索与结果跳转，完善滚动跟随，并支持可选的输出着色。
- 扩展 Claude、Codex 等智能体的配额与用量展示，增加用量缓存、刷新控制和统计完整性提示，任务监控汇总项目与会话状态。
- 集中管理智能体默认权限和启动参数，完善会话命名、项目图标、快捷命令和语音识别语言设置。
- 更新设置页、空白工作区和浮层样式，统一复制成功反馈，合并重复通知，并补充会话启动等操作的交互反馈。
- 升级 Ant Design 6、Tailwind CSS 4、TypeScript 7 与终端渲染插件，调整编辑器加载和后台实例释放策略。

## 问题修复

- 修复网络或会话错误恢复后，标签页红点仍长期保留的问题：开始重试时保留错误标记，确认后续成功回复后自动清除；补齐遗漏运行状态事件时的恢复逻辑，并正确识别 Hook 完成事件。
- 修复终端网格尺寸与 PTY 不一致、Unicode 和组合 Emoji 列宽、换行及固定行高处理，完善隐藏后恢复显示、文件拖入和输入提交。
- 改善终端中断与用户响应后的状态同步，统一工作区标签、侧栏和任务监控的会话状态反馈。
- 修复编辑器主题同步、隐藏与分屏切换时的实例管理，并在宿主仍存活时保留编辑历史和视图状态。
- Office 文档预览跟随应用主题，完善文件加载、错误提示和离线资源打包。
- 修复 Git 状态解析和变更预览边界，校验预览大小，并默认启用可配置的远程自动获取。
- 限制全文搜索结果体积，修正匹配预览坐标，并协调搜索和索引更新，减少重复扫描。
- 完善文件操作校验、多窗口退出时的未保存文档处理，以及设置保存和跨窗口同步；修复侧栏设置菜单和行操作浮层定位。

## 升级说明

- 从 Termflow 升级时，请先保存工作并关闭旧版应用，再运行 Krosna 安装包。首次启动会迁移可兼容的旧版数据，并保留原始数据。
- 新建项目配置使用 `.krosna/`，运行时命令使用 `krosna`；自行编写的相关脚本请相应更新。
